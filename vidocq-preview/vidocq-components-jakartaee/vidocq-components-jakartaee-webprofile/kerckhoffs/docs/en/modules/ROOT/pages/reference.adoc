= Reference
:description: Modules of Kerckhoffs and how to deploy them.

== Modules

[cols="1,1,3"]
|===
| Artifact | Java module | Role

| `kerckhoffs-core` | `io.vidocq.kerckhoffs.core` | `IdentityStoreHandler` chain, in-memory identity store, PBKDF2 password hash, the built-in BASIC and FORM mechanisms, `SecurityContext`. No CDI.
| `kerckhoffs-cdi` | `io.vidocq.kerckhoffs.cdi` | Build compatible extension: declares the identity stores of `@InMemoryIdentityStoreDefinition`, the handler and the mechanisms of `@BasicAuthenticationMechanismDefinition` and `@FormAuthenticationMechanismDefinition` as beans, and fails the start on an invalid definition.
| `kerckhoffs-authentication` | `io.vidocq.kerckhoffs.authentication` | Jakarta Authentication 3.1: the Servlet Container Profile that drives a mechanism (minimal slice).
| `kerckhoffs-authorization` | `io.vidocq.kerckhoffs.authorization` | Jakarta Authorization 3.0: the policy factory and the default policy that answers web resource permissions from the security constraints (minimal slice).
| `kerckhoffs-foy` | `io.vidocq.kerckhoffs.foy` | Engine adapter: places a mechanism and the policy in service on the request authentication and access control hooks of Foy.
|===

The extension works at build and is frozen by `vidocq:generate`; the check of the definitions
runs in an observer of `Startup`, so an invalid definition still stops a frozen application.

== Deviations from the reference implementation

WARNING: The qualifiers of a BASIC mechanism differ from Soteria 4.0.2's (KERCK-20261118-03).
A `@BasicAuthenticationMechanismDefinition` whose `qualifiers` is left to its default
`{BasicAuthenticationMechanism.class}`, or written out the same, gives a mechanism that is
`@BasicAuthenticationMechanism` and also `@Default`; Soteria gives it its qualifiers alone, so
the mechanism is not `@Default` there. An explicit `qualifiers = {}` gives a mechanism that is
`@BasicAuthenticationMechanism` and `@Default`; Soteria gives it no `@BasicAuthenticationMechanism`.
A portable application selects it with `@BasicAuthenticationMechanism` when `qualifiers` is left
to its default, with `@Default` when it writes `qualifiers = {}`, or lets the default handler find
it (§2.2.1).

== Deploying on an application server

WARNING: Kerckhoffs is not tested on an application server yet. Jakarta Security is a feature
of such servers: keep their own security feature on only if you do not ship Kerckhoffs, and do
not ship both. Its only container adapter, `kerckhoffs-foy`, plugs it into Foy: on another server
nothing places its mechanisms in service. The tested `<exclusions>` and the Open Liberty WAR arrive with the
`kerckhoffs-it-other-containers` module (milestone K6); there is no `kerckhoffs-it-openliberty` module yet.
