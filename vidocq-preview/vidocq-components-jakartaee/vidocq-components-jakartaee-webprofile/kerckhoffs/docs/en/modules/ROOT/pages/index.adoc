= Kerckhoffs
:description: Jakarta Security 4.0 implementation for the Vidocq ecosystem.

[.text-center]
image::kerckhoffs-logo.png[Kerckhoffs,300,role=module-logo]

[.lead]
Kerckhoffs implements {spec-security-4-0}[Jakarta Security 4.0]: HTTP authentication
mechanisms, identity stores and the security context of a Jakarta EE application, with zero
third-party dependency and strict Java Modules.

NOTE: Kerckhoffs is a preview component: released, not complete and not certified. Identity stores, the built-in `Pbkdf2PasswordHash`, the built-in BASIC, FORM and custom FORM mechanisms, an application's own mechanism, `SecurityContext.authenticate`, `@RememberMe` and Jakarta Authorization for web resources are in (milestones K0 to K3); the database and LDAP identity stores and OpenID Connect are not. The TCK figures are on the xref:tck.adoc[TCK] page; the design of
record is `PLAN.md` in the {repo-vidocq}/src/branch/main/vidocq-preview/vidocq-components-jakartaee/vidocq-components-jakartaee-webprofile/kerckhoffs[repository].

== Origin of the name

Auguste Kerckhoffs (1835–1903) stated in 1883 that a cryptographic system must remain secure
even if everything about it, except the key, is public. The brick applies that rule to the
platform: the security machinery is open, inspectable and generated at build time; only the
credentials stay secret.

NOTE: "Kerckhoffs" names the component. Besides Jakarta Security 4.0 it carries, as separate modules, the slices of Jakarta Authentication 3.1 and Authorization 3.0 it stands on.

== Position in the ecosystem

Kerckhoffs depends on the Jakarta APIs only. Under Vidocq, its runtime extension assembles it with
xref:{page-component-version}@foy::index.adoc[Foy] (Servlet), xref:{page-component-version}@vauban::index.adoc[Vauban]
(CDI) and xref:{page-component-version}@peano::index.adoc[Peano] (Expression Language); REST resources are protected
when xref:{page-component-version}@cassini::index.adoc[Cassini] serves them as a servlet of Foy. See
xref:concepts.adoc[Concepts] for how a request goes through them.
