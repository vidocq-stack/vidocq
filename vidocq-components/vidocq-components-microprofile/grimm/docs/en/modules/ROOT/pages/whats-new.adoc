= What's new
:description: Everything that changed in this component since the {release-version} release.

[.lead]
New in the `{project-version}` development line — everything listed here landed **after the {release-version} release** and is not part of it. Every entry links to the section that documents it, and those sections carry the [.tag-new]#NEW# badge. Each brick of the suite keeps its own page of this kind; xref:home::whats-new.adoc[the ecosystem index] gathers them. When the next release train ships, this page is frozen with it and restarts empty on the dev line.

* xref:internals.adoc#response-schema[A JAX-RS `Response` is an opaque object in the document] [.tag-new]#NEW# — a resource method that returns `jakarta.ws.rs.core.Response` gets a `type: object` schema, and the document publishes no `Response`, `StatusType`, `MediaType`, `URI`, `Locale`… components, which collided by simple name with classes of the application. `grimm-processor` accepts `Response` as a return type, so a resource class that returns one, and otherwise only scalars, is described at build instead of by the scan. An `mp.openapi.schema.jakarta.ws.rs.core.Response` override still wins (BUG-20261110-01).
