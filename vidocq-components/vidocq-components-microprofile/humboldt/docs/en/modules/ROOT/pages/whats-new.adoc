= What's new
:description: Everything that changed in this component since the {release-version} release.

[.lead]
New in the `{project-version}` development line — everything listed here landed **after the {release-version} release** and is not part of it. Every entry links to the section that documents it, and those sections carry the [.tag-new]#NEW# badge. Each brick of the suite keeps its own page of this kind; xref:home::whats-new.adoc[the ecosystem index] gathers them. When the next release train ships, this page is frozen with it and restarts empty on the dev line.

* xref:reference.adoc#client-spans[A REST client call that gets no response exports its CLIENT span] [.tag-new]#NEW# — with Cyrano or `cassini-client`, a call that fails before a response (refused connection, timeout, I/O error, interrupt) ends its CLIENT span with status `ERROR`, `error.type` and the exception recorded, instead of leaving it open and never exported (Vidocq/vidocq#686).
* xref:reference.adoc#client-spans[The CLIENT span of an SSE call ends] [.tag-new]#NEW# — a MicroProfile Rest Client method that returns a `Publisher` ends its CLIENT span once the response headers arrive, with the response status, or in error when the connection fails before any response (Vidocq/vidocq#822).
* xref:reference.adoc#otlp-protocol[OTLP/HTTP exports protobuf by default] [.tag-new]#NEW# — with no `otel.exporter.otlp.protocol`, the `otlp` exporters post `application/x-protobuf`, the OpenTelemetry default, instead of OTLP/JSON. A receiver that accepts only JSON needs `otel.exporter.otlp.protocol=http/json` (xref:migration.adoc#upgrading-from-0-4[Upgrading from Humboldt 0.4]).
