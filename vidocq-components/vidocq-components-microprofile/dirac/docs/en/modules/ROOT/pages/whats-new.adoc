= What's new
:description: Everything that changed in this component since the {release-version} release.

[.lead]
New in the `{project-version}` development line — everything listed here landed **after the {release-version} release** and is not part of it. Every entry links to the section that documents it, and those sections carry the [.tag-new]#NEW# badge. Each brick of the suite keeps its own page of this kind; xref:home::whats-new.adoc[the ecosystem index] gathers them. When the next release train ships, this page is frozen with it and restarts empty on the dev line.

* xref:reference.adoc#bindings-and-inherited-metrics[Metrics on inherited methods are registered] [.tag-new]#NEW# — a bean that inherits a `@Counted` or `@Timed` method from a superclass, of a dependency jar too, or a default method from an interface, and does not override it, carries that metric, named after the class or interface that declares the method. Each call threw `IllegalStateException: Counter metric was removed from registry`. An interface of the deployment no longer registers metrics of its own, which never moved. A superclass that cannot be linked at run time, because a method names a type of an absent optional dependency, ends the walk with a `WARNING`, and the bean keeps its own metrics, where the whole bean was skipped (DRC-011, DRC-012).
* xref:reference.adoc#bindings-and-inherited-metrics[Metrics carried by an interceptor binding count] [.tag-new]#NEW# — a method, constructor or class counted or timed through an application interceptor binding annotated `@Counted` or `@Timed`: the interceptors now name the metric as the scan registered it. A method threw `IllegalStateException: Counter metric was removed from registry` on every call, and the counter of a constructor or a class never moved (DRC-014).
* xref:usage.adoc#inherited-gauges[Inherited gauges] [.tag-new]#NEW# — a `@Gauge` method a bean inherits from a superclass, of a dependency jar too, or as a default method of an interface, is registered and read on the bean, under the name its declaring class gives it; it was never registered. Two unrelated beans that carry one gauge id give one gauge, read on the bean whose class name comes first, with a `WARNING` naming both, where one was picked at random (DRC-013, DRC-012).
* xref:usage.adoc#gauge-bean[A gauge is read on one reference of its bean] [.tag-new]#NEW# — the bean of a gauge is found whatever its qualifiers, and for a class with a bounded type variable, including one that declares a producer, which never runs for a read. Each read of these gauges failed with `DiracException: Unable to read gauge value`. A `@Dependent` bean is created once, at the first read, and destroyed when the container stops; each read created one, which Weld kept until the container stopped (DRC-015 to DRC-018, Vidocq/vidocq#652).
