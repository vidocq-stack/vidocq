# JLINK.md

This document describes the M9 smoke check for Java Modules/jlink through the `dirac-mp-metrics-api` artifact.

## Current state

- `dirac-api`, `dirac-processor`, `dirac-core`, `dirac-cdi-vauban`, `dirac-rest` and `dirac-examples` are explicit modules (`module-info.java` in `src/main/java`); `dirac-bench` is not.
- The `jlink` blocker is lifted by the reactor artifact `dirac-mp-metrics-api` (module `microprofile.metrics.api`), which repackages `microprofile-metrics-api` with an explicit `module-info.class`. It joins the reactor through the `repackaged-api` profile of `dirac/pom.xml`, active except in an IntelliJ import.
- The source JAR in the Maven cache is not modified.

## Scripts

Run from the Dirac folder (`vidocq-components/vidocq-components-microprofile/dirac`).

- `run-jlink-smoke.sh`
  - installs `dirac-mp-metrics-api` + `dirac-api` + `dirac-core` (`clean install -DskipTests`, into `.tck-repository/` of this folder),
  - validates the modules (`java --validate-modules`),
  - builds the image `target/dirac-image-smoke` with `--add-modules io.vidocq.dirac.core` (jlink output in `target/jlink-smoke.out`).
- `run-jlink-smoke-ci.sh`
  - blocking wrapper (propagates errors). No workflow of the monorepo runs it.
- `run-jlink-smoke-m92.sh`
  - earlier variant (M9.2): modularises the `microprofile-metrics-api-5.1.1.jar` (from `.tck-repository/`, else `~/.m2/repository`) with a `module-info` generated by `jdeps`, then builds `target/m92-jlink/image`.

The Maven call of each script reads and writes `.tck-repository/` in this folder (`TCK_LOCAL_REPOSITORY` moves it), above `~/.m2/repository`, which it only reads: the install of a branch never replaces the published Dirac snapshot the other builds of the machine resolve (BUG-20261123-57).

## Local execution

```bash
./run-jlink-smoke.sh
./run-jlink-smoke-ci.sh
```

## Maven profile

```bash
./mvnw -ntp -N -Pjlink-smoke verify
```

- The profile calls `run-jlink-smoke-ci.sh` in the `verify` phase.
- The profile is blocking: any `jlink` failure fails the build.

## Expected result

- `jlink` completes without error,
- image available in `target/dirac-image-smoke`,
- module `microprofile.metrics.api` visible in `--list-modules`.
