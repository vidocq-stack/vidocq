== gRPC

* xref:modules/chappe-grpc-client.adoc[A gRPC client] [.tag-new]#NEW# — the new module `chappe-grpc-client` calls unary gRPC methods over HTTP/2, in cleartext with prior knowledge or over TLS with ALPN `h2`, on Chappe's own framing and HPACK codec (Vidocq/vidocq#837). It reads `grpc-status` and `grpc-message` from the trailers, which the JDK `HttpClient` cannot, sends the deadline as `grpc-timeout`, honours both flow-control windows and `SETTINGS_MAX_CONCURRENT_STREAMS`, and reports every failure of the network as a gRPC status (`UNAVAILABLE`, `DEADLINE_EXCEEDED`). Messages are opaque bytes; no dependency outside the JDK.
* xref:reference.adoc#hpack-request[`HpackEncoder.encodeRequest`] [.tag-new]#NEW# — `chappe-http` encodes request header blocks too: the four request pseudo-header fields, then the fields under the rules of a response.
