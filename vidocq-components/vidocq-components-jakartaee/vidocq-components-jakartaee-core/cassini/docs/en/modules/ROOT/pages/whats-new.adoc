== Transports

* xref:internals.adoc#shared-prefix[The REST stack says whether a resource matches a path] [.tag-new]#NEW# — `CassiniHttpAdapter.hasResourceAt(String)` and `ChappeHttpAdapter.serves(Request)` answer whether a resource matches the path of a request for some HTTP method, without dispatching it. The Vidocq runtime asks it when the REST resources share their prefix with static files or servlets (Vidocq/vidocq#802), so a path no resource matches goes to the next handler of the prefix. An adapter that does not override `hasResourceAt` serves every path, as before.
