= Bodoni
:description: Jakarta Standard Tag Library 3.0 implementation — zero third-party dependency, native Java Modules, portable tag handlers; build-time inlining by Ibarra is planned, on standby. B5: official Tags TCK runner, 541/541 after the TCK fixes (first baseline 452/541), not a certification.

[.lead]
Bodoni is the Jakarta Standard Tag Library 3.0 (JSTL) implementation of the Vidocq ecosystem, in pure Java 25: the `c:`, `fmt:`, `fn:`, `x:` and `sql:` libraries as standard, portable tag handlers, with no dependency beyond the JSTL API and the JDK — and, when Ibarra precompiles the pages, the hot core tags inlined at build time (planned, on standby: see xref:concepts.adoc[Concepts]).

[IMPORTANT]
====
Milestone **B4** is delivered: the five libraries, `c:` (core), `fn:` (functions), `fmt:` (I18N and formatting), `x:` (XML processing) and `sql:` (relational database access), are implemented. Milestone **B5** is delivered: the official Tags TCK runner; after the TCK fixes the official Tags tests pass 541 of 541 on Ibarra + Foy + Peano (first baseline 452 of 541), a measurement, not a certification: see xref:tck.adoc[TCK status]. Under Peano with `peano.reflection=deny`, add the optional `bodoni-peano` adapter: xref:reference.adoc#bod-001[BOD-001].
This documentation describes the `{project-version}` development line; every page states what exists today.

== Origin of the name

Giambattista Bodoni (1740–1813), printer to the Duke of Parma, contemporary and rival of Joaquín Ibarra. His _Manuale Tipografico_ (1788; posthumous 1818 edition) is a catalogue of standard, ready-made type that any printer composes pages with. See https://en.wikipedia.org/wiki/Giambattista_Bodoni[the Wikipedia article].

JSTL is the standard catalogue of tags every page composes with. Ibarra (Jakarta Pages 4.0) composes and prints the pages; Bodoni supplies the type — the same kind of nod as Ibarra's to Cervantes.

== Three identifying traits

. **Zero third-party dependency** — the JSTL API jar and JDK modules (`java.xml`, `java.sql`, `java.naming`, `java.net.http`). No Apache Taglibs, no Xalan.
. **Portable** — standard tag handlers that run unchanged on Ibarra, Jasper or Open Liberty. Bodoni depends on APIs only; the Vidocq runtime extension assembles it with Ibarra and Peano.
. **Codegen where it pays** — an optional `bodoni-ibarra` module lets Ibarra inline `c:if`, `c:choose`, `c:forEach`, `c:set`, `c:out` and friends at build time, tested differentially against the standard handlers (planned, on standby).

== Position in the ecosystem

Bodoni sits in the Jakarta EE web tier next to Peano (Expression Language 6.0) and Ibarra (Pages 4.0). It depends on neither: page expressions are evaluated by whatever EL implementation the container uses, and pages are translated by whatever Pages container runs them. Under Vidocq, the runtime extension brings Bodoni + Ibarra + Peano. It is required by Jakarta EE Web Profile 11 (Vidocq issue https://codefloe.com/Vidocq/vidocq/issues/266[#266]).
