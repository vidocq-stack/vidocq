== Spec-mandated dynamic behaviour (target)

* `sql:setDataSource driver="…"` loads a JDBC driver class by name, as the spec requires.
* A `String` data source is looked up as `java:comp/env/<path>` through `new InitialContext()`, then interpreted as a JDBC parameter string `url[,[driver][,[user][,password]]]`. Bodoni provides no naming implementation.

== Compatibility

* **Java**: 25 (LTS).
* **Maven**: 3.9.16 (Model 4.0.0).
* **Java Modules**: strict, every module has a `module-info.java`.
* **Virtual threads**: no `synchronized`, no `ThreadLocal`.
* **Specs**: targets {spec-tags-3-0}[Jakarta Standard Tag Library 3.0] on Jakarta Pages 4.0, Servlet 6.1 and Expression Language 6.0.
