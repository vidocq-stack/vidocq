== Integration

* xref:internals.adoc#serves-request[Foy says whether the application serves a request] [.tag-new]#NEW# — `FoyChappeBoot.Mounted.serves(Request)` answers whether a servlet maps the path or the container default servlet has a file, a welcome file or a directory redirect for it, without handling the request: no filter runs and no session is touched. The Vidocq runtime asks it when the servlets share their prefix with static files or REST resources (Vidocq/vidocq#802), so a request the application does not serve goes to the next handler of the prefix.
