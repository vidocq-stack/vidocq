== Maven artefacts

[cols="1,3"]
|===
| Artefact | Role

| `io.vidocq.mpserver:vidocq-mps-parent:0.1.0-SNAPSHOT`
| Parent POM (Model 4.1.0)

| `io.vidocq.mpserver:vidocq-mps-spi:0.1.0-SNAPSHOT`
| Public SPI (BuildStep, BuildItem, Recorder)

| `io.vidocq.mpserver:vidocq-mps-core:0.1.0-SNAPSHOT`
| Runtime engine (Vauban + plumbing)

| `io.vidocq.mpserver:vidocq-mps-core-extensions:0.1.0-SNAPSHOT`
| Shipped extension pack

| `io.vidocq.mpserver:vidocq-mps-maven-plugin:0.1.0-SNAPSHOT`
| Maven plugin to build the app

| `io.vidocq.mpserver:vidocq-mps-examples:0.1.0-SNAPSHOT`
| Examples (REST, CDI, JDBC, transactions)

| `io.vidocq.mpserver:vidocq-mps-integration-tests:0.1.0-SNAPSHOT`
| Multi-extension integration tests
|===
